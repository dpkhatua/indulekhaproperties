# Indurekha Properties website

Static site: index.html, styles.css, script.js, favicon.svg. No build step.

## Preview
Open index.html in a browser, or run `python3 -m http.server` in this folder.

## Publish (all free options)
- Netlify: drag this folder onto app.netlify.com/drop
- Cloudflare Pages or GitHub Pages: upload the folder
- Then point your domain (for example indurekhaproperties.com) at it in the host's domain settings.

## To edit
- Contact details: add email and phone in the "Visit us" section of index.html.
- Services text: "What we do" section.
- Colours and fonts: variables at the top of styles.css.
